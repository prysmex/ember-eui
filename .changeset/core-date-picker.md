New `EuiDatePicker`: a port of upstream's date picker, without moment. A text input opens a calendar in a popover, or `@inline={{true}}` shows the calendar in the page. The value is a `YYYY-MM-DD` string (a `Date` or a moment is read too; `@onChange` always gets a string). Typed text is committed on Enter, on blur or on a pick, never while typing; text that is not a date, or names a day that cannot be chosen, stays in the input with the invalid look and calls `@onInputError`. The calendar is a keyboard-accessible grid with month and year selects; names, the first day of the week and the date order come from `@locale` through the browser's `Intl`. Supports `@minDate`, `@maxDate`, `@excludeDates`, `@includeDates`, `@filterDate`, `@openToDate`, `@dayClassName`, `@onClear`, the form states, `<:prepend>` and `<:append>`, and `@controlOnly`; it works inside modals and flyouts. `@showTimeSelect` adds a time list beside the calendar and makes the value a UTC ISO instant, shown and chosen as a wall clock in `@timeZone` (`'local'`, `'utc'`, an IANA name, or a fixed offset such as `'-03:00'`, upstream's `utcOffset`); `@showTimeSelectOnly` picks a time of day, `HH:mm`. A time that does not exist on a DST change day moves forward, a repeated one means its first occurrence, and a stored second occurrence is kept. Also `@timeIntervals`, `@injectTimes`, `@minTime`, `@maxTime`, `@excludeTimes`, `@seconds`, `@hour12`, `@adjustDateOnChange` (default `false`), and `componentDefaults.EuiDatePicker.locale` in `euiConfig`. On phones (a coarse primary pointer) and in Capacitor apps (`window.Capacitor.isNativePlatform()`; no Capacitor import) the picker renders the OS input instead: `<input type="date">`, `datetime-local` (the wall clock in `@timeZone`) or `time`, with `min`, `max` and `step`, the same arguments and the same value strings. Every value the OS returns is checked as typed text is: outside the limits it stays in the input with the invalid look, never reaches `@onChange`, and is reported to `@onInputError` when focus leaves the input. `@native` (`'auto'`, the default, `true` or `false`) and `componentDefaults.EuiDatePicker.native` choose the path; `@inline` always shows the calendar, and so does auto when an argument the OS picker cannot honour is given (`@filterDate`, `@excludeDates`, `@includeDates`, `@excludeTimes`, `@injectTimes`, `@dayClassName`). A read-only picker shows a read-only text input there. Also: a press in a popover opened from a flyout that closes on outside clicks no longer closes the flyout.
