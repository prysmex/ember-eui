New package: `EuiSheet`, an Airtable-like data-entry grid built on `EuiDataGrid`. Controlled data (`@records` in, `@onChange(changeSet)` out), keyboard editing, range selection, copy and paste as TSV, five field types (text, number, checkbox, single select, date), cell errors (a text a type cannot read is kept and shown, not saved), `@validate` for record, cross-row and async rules, messages through `eui-i18n`, and a contract for custom cells and editors.
