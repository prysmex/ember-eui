## Parts derived from EUI

- **Component styles**: `src/utils/eui/styles.generated.ts` (built into
  `dist/`) is generated by `scripts/generate-eui-styles.mjs` from the style
  sources of `@elastic/eui` 123.1.0. Each module is marked with its path
  inside the package (e.g. `// @elastic/eui/es/components/button/...`), and
  `internal/spikes/eui-latest/upstream-sources.json` in the repository lists
  every source file with its checksum.
- **Icons**: `vendor/icon/svgs` holds EUI's icon SVGs; see
  [vendor/icon/NOTICE.txt](vendor/icon/NOTICE.txt).
- **Component behaviour**: many components port the structure, behaviour,
  accessibility and helper logic of EUI's React components (e.g. popover
  positioning, the data grid, the combo box, the super date picker and the
  flyout session manager) to Ember.
- **Legacy theme CSS**: `vendor/eui_theme_light.min.css` and
  `vendor/eui_theme_dark.min.css` are compiled from an earlier EUI release
  (the Amsterdam theme) and are covered by Elastic's license for that
  release.
- **Documentation** (in the repository and on the docs site, not in this
  package): the examples and much of the prose in the component docs are
  adapted from EUI's documentation site (`packages/website` in the EUI
  repository).
