# Success

<EuiText>

Use this callout to notify the user of an action that successfully completed. Use success callouts sparingly, as callouts are typically used for things that are broken rather than things that succeed.

</EuiText>

```hbs template
<EuiCallOut @title="Good news, everyone!" @color="success">
  <p>
    I have no news. Which is good! And
    <EuiLink @href="#">here&rsquo;s a link</EuiLink>.
  </p>
</EuiCallOut>
```
