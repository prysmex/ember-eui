# Elastic

<EuiText>

The **EuiLoadingElastic** loader is great for full page or Elastic product loading screens.

</EuiText>

```gjs component
import { EuiLoadingElastic } from '@ember-eui/core/components';

<template>
<div>
  <EuiLoadingElastic />
  &emsp;
  <EuiLoadingElastic @size="l" />
  &emsp;
  <EuiLoadingElastic @size="xl" />
  &emsp;
  <EuiLoadingElastic @size="xxl" />
</div>
</template>
```
