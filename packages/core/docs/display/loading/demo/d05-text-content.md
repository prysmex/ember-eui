# Text content (Ember EUI extension)

<EuiText>

**EuiLoadingContent** shows animated placeholder lines where text will appear. It renders a maximum of 10 lines.

</EuiText>

```gjs component
import { EuiLoadingContent } from '@ember-eui/core/components';

<template>
<EuiLoadingContent @lines={{4}} />
</template>
```
