<EuiText>

The toolbar above the grid holds the column selector (search, show/hide and
drag to reorder), the sort popover (with `@sorting`), the keyboard
shortcuts, the display options (density and lines per row) and the
fullscreen toggle. Below `@minSizeForControls` (479px) only the right side
controls show. Columns can also be reordered by dragging their headers, see
[schema and columns](/docs/core/docs/tabular/data-grid/schema-and-columns).

</EuiText>
